## 👨‍💻 Sobre mí

Soy desarrollador de software con experiencia profesional en el ecosistema .NET, desarrollo de herramientas internas, consultas SQL y automatización de procesos.

Actualmente trabajo con **C#, .NET, ASP.NET Core y SQL Server**, mientras desarrollo proyectos personales para fortalecer mis conocimientos de arquitectura, diseño de APIs y persistencia de datos.

Me interesa comprender no solo cómo implementar una funcionalidad, sino también cómo organizar el código, separar responsabilidades y tomar decisiones técnicas que faciliten el mantenimiento y la evolución del software.

- 🔹 **Especialidad:** desarrollo backend con C# y ASP.NET Core.
- 🔹 **Bases de datos:** SQL Server, PostgreSQL y diseño de consultas.
- 🔹 **Diseño de software:** principios SOLID, separación de responsabilidades y diseño modular.
- 🔹 **Herramientas:** Git, GitHub, Linux y Docker.
- 🔹 **Exploración tecnológica:** Laravel, Python, Go y desarrollo multiplataforma.

Mi objetivo es seguir creciendo como desarrollador backend, profundizar en el diseño de sistemas y participar en proyectos donde la calidad técnica y la resolución de problemas sean fundamentales.
